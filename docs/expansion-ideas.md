# 專案擴充建議

用來讓作品集更專業的擴充方向，依「作品集效益 vs 開發成本」排序，數字越小越優先。

1. **可證明公平（Provably Fair）展示頁** — 效益最高，且已有一半基礎（Slots 已改成種子式 RNG）。做法：開局前公開種子雜湊，開獎後公開種子本身，附上讓玩家自行驗證的演算法說明。博弈類作品集最容易讓人留下印象的加分項。
2. **對帳與稽核紀錄頁面** — 交易紀錄資料表已有大部分欄位（金額變動前後、原因、round id），主要缺一個前端查詢介面，能凸顯「金流可追溯」的思維。
3. **CI pipeline（GitHub Actions）** — 開發成本低、訊號強。跑 lint + 單元測試 + build，PR 上顯示 bundle size 差異，證明有工程化習慣而不只是會寫功能。
4. **E2E 測試（Playwright）** — 針對「連續下注」「購物車超買」「結帳競態」這類已經抓到過的 bug 寫回歸測試，展示用測試防止同類問題再發生的意識。
5. **RTP 模擬器/儀表板** — 跑 N 次模擬並畫圖比對「理論賠付率 vs 實際派彩」，證明理解機率設計而不只是丟隨機數字。
6. **i18n 國際化** — 把中英混用的字串抽出來，加語言切換，對商業化包裝更有說服力。
7. **無障礙與鍵盤操作** — 補鍵盤下注、開獎結果的語音播報（aria-live），是很多同類作品集容易缺少的細節。
